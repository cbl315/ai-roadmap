🎯 核心理念

先原生 SDK，后框架。先用 Anthropic / OpenAI 原生 SDK 理解 tool_use 消息协议和 agentic loop 的 while 循环，Module 08 才引入 LangGraph / LangChain 做对比。

同时覆盖 Claude 与 GPT 两家 API，把「概念」和「某家的写法」区分开，避免被单一 SDK 绑架认知。

💡 学习节奏建议

01–03 快速通过：跑通示例、做完练习即可前进，不必追求完美。

04 多花时间：agentic loop 是核心，反复迭代追踪、上下文管理与回归测试。

05 学完原生立刻学 MCP，用真实客户端验证打通；09 先跑通最小闭环，再补评估与可观测性。
